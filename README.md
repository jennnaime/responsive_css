# MacBook Neo

## Topic

Advertising website for the new Apple MacBook Neo laptop.

## Project goal

To present the MacBook Neo to students, designers and developers — show its features, colors and benefits in a clean, responsive interface.

## Local opening

1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. Or use a local server: `python -m http.server`

## Deployed URL

https://username.github.io/macbook-neo/

## Limitations

The contact form is a static demonstration. It does **not** send or store any data. Native HTML validation is used only to demonstrate form behavior. Real message delivery would require a backend or third-party service.
